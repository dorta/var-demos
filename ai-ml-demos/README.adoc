= AI/ML Demos

Classification, object detection, HD video and experimental hand gestures.

== Support

* i.MX 8M Plus: current test platform; see each demo's limitations;
* i.MX 93: Ethos-U65 image/video/camera classification and detection;
* DART-MX95: Neutron image/video/camera classification and detection;
  see link:camera-vision/README.md[Camera, decoder and model notes].

== Install

Run as `root` on the target:

[source,console]
----
curl -fsSL https://raw.githubusercontent.com/dorta/var-demos/demos/install.sh | sh
----

== Run

[source,console]
----
var-demos
----

`var-demos` shows a terminal menu; select the AI / ML category. Use the arrows
and `Enter` to select a demo. Press `Esc` to stop and return to the menu.
Press `l` while running to view diagnostic logs. Use `var-demos --plain` for
terminals without curses support.
Serial consoles use a compact VT100-compatible layout. After a demo ends,
review its measured statistics and press `Enter` or `Esc` to return.
The HD demo asks which video to play and shows each sample's resolution.
The shared demos appear first: classification (image, video, camera), then
detection (image, video, camera). Optional extras follow. Camera demos ask
for the configured capture resolution; fullscreen is the default.
High-rise buildings A and B are available in 720p and 1080p. The default is
720p. MX93 uses MJPEG versions; MPlus and MX95 use H.264 MP4 versions.

Continuous operation requires adequate cooling. Demos reduce frame rate when
hot and pause inference to cool before the kernel's thermal protection trips.

Models and media are hosted on DigitalOcean Spaces, downloaded with curl,
and verified with SHA-256 during installation. Git LFS is not used.
Developer documentation is available inside each demo folder.

Run the install command again to update code and media. Files that already
match the current SHA-256 manifest are reused.

== Uninstall

Run the installed uninstaller as `root`:

[source,console]
----
var-demos --uninstall
----

Use `--dry-run` together with `--uninstall` to preview the paths first.
