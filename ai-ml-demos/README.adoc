= AI/ML Demos

Ready-to-run AI/ML demos for Variscite Systems on Module. The installer
detects the target SoC and installs only compatible demos.

== Support

* i.MX 8M Plus: validated;
* i.MX 93: pending hardware validation;
* i.MX 95: pending hardware validation.

Available on i.MX 8M Plus:

* link:classification/[Classification] for images, videos, and cameras;
* link:detection/[Object detection] for images, videos, and cameras;
* link:high-resolution-video-detection/[High-resolution video detection].

== Install

Run as `root` on the target:

[source,console]
----
curl -fsSL \
  https://raw.githubusercontent.com/varigit/var-demos/demos/ai-ml-demos/install.sh \
  | sh
----

The default destination is `/opt/var-demos/ai-ml`. Useful options:

[source,console]
----
./install.sh --list
./install.sh --dry-run
./install.sh detection
./install.sh --prefix /home/root/ai-ml
----

== Run

Prepare an SSH session for OpenCV through XWayland:

[source,console]
----
export XDG_RUNTIME_DIR=/run/user/0
export DISPLAY=:0
unset WAYLAND_DISPLAY QT_QPA_PLATFORM
----

Then run a demo from its directory:

[source,console]
----
cd /opt/var-demos/ai-ml

(cd classification && python3 image_classification.py)
(cd detection && python3 image_detection.py)
(cd high-resolution-video-detection && \
  python3 high-resolution-video-detection.py --combination 2)
----

OpenCV demos use fullscreen by default. Press `Esc` to close video and camera
demos, or pass `--windowed` to open a regular window.

For a camera demo, find the capture device with
`v4l2-ctl --list-devices` and pass it explicitly:

[source,console]
----
cd /opt/var-demos/ai-ml/detection
python3 realtime_detection.py --camera /dev/video4
----
