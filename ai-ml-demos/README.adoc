= AI/ML Demos

Ready-to-run AI/ML demos for Variscite Systems on Module.

== Support

* i.MX 8M Plus: validated;
* i.MX 93: pending hardware validation;
* i.MX 95: pending hardware validation.

== Install

Run as `root` on the target:

[source,console]
----
curl -fsSL \
  https://raw.githubusercontent.com/dorta/var-demos/demos/ai-ml-demos/install.sh \
  | sh
----

== Run

[source,console]
----
var-ai
----

`var-ai` shows a terminal menu for the detected platform. Use the arrow keys
and `Enter` to select a demo. Press `Esc` to stop and return to the menu.
Press `l` while running to view diagnostic logs. Use `var-ai --plain` for
terminals without curses support.
Serial consoles use a compact VT100-compatible layout. After a demo ends,
review its measured statistics and press `Enter` or `Esc` to return.
The HD demo asks which video to play and shows each sample's resolution.

Continuous operation requires adequate cooling. Demos reduce frame rate when
hot and pause inference to cool before the kernel's thermal protection trips.

Models and media are downloaded separately and verified with SHA-256 during
installation. Developer documentation is available inside each demo folder.

Run the install command again to update code and media. Files that already
match the current SHA-256 manifest are reused.

== Uninstall

Run the installed uninstaller as `root`:

[source,console]
----
/opt/var-demos/ai-ml/install.sh --uninstall
----

Use `--dry-run` together with `--uninstall` to preview the paths first.
