= Classification

Classify the main subject in an image, video or camera frame on i.MX 8M Plus.
MobileNet V1 runs through TensorFlow Lite and the VX NPU delegate.
Classification labels the whole frame; it does not locate individual objects.

== Run

Use the link:../../README.md[root installer], then run `var-demos`.
Choose *AI / ML* and an image, video or camera classification demo.
The manager selects an available camera; assets are downloaded and verified.

Fullscreen is the default. Camera fullscreen uses a central crop;
windowed mode retains the full frame. Press `Esc` to stop.
The overlay shows results, performance and the `soc-thermal` temperature.

== Developer options

Installed directory: `/opt/var-demos/ai-ml/classification`.
Each script supports `--help`; `--windowed` requests a regular window.
Direct GUI execution needs the display environment set by the manager.
Prefer `var-demos` for normal use.
