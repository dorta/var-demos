= Object detection

Locate and label objects in images, videos or camera frames on i.MX 8M Plus.
SSD MobileNet V1 runs through TensorFlow Lite and the VX NPU delegate.

== Run

Use the link:../../README.md[root installer], then run `var-demos`.
Choose *AI / ML* and an image, video or camera object-detection demo.
The manager selects an available camera; assets are downloaded and verified.
HD/Full HD footage uses the separate high-resolution video demo.

== Display and stability

The overlay shows boxes, labels, confidence, FPS, inference time and the
`soc-thermal` temperature. Camera fullscreen uses a central crop.
Press `Esc` to stop. Thermal pacing can reduce FPS or pause inference;
adequate cooling is required.

A 10-minute camera check on 2026-10-05 processed 9,414 frames at 15.8 FPS
overall, with 9.0 ms average inference and a 78 C SoC peak. Stop/restart
also completed. This is not multi-hour or visual-flicker certification.

== Developer options

Installed directory: `/opt/var-demos/ai-ml/detection`.
Each script supports `--help`; use `--camera` for an explicit device and
`--windowed` for a regular window. Direct GUI execution needs the display
environment set by the manager. Prefer `var-demos` for normal use.
